# notebook-grid-maker-visualizer-csvwriter

Generates the 341-point hexagonal base grid (80 m spacing, ~780 m
radius) and selects indexed subsets for `102geom`, `160geom`, and the
donut variants. Exports CSV index lists + NPY coordinate arrays to
`nugget/other/`.
