# README

Project overview for **nugget** — NeUtrino experiment Geometry
optimization and General Evaluation Tool. Python package for
optimizing neutrino-observatory detector geometries with ML.

See [README.md](../../README.md).

## Highlights
- Geometries: continuous / dynamic / evanescent / free-point.
- Losses: Fisher info, light yield, LLR, SNR.
- Surrogates: neural nets + symbolic regression.
- Samplers, optimization pipelines, vis tools.

## Install
`pip install -e .` (Python ≥ 3.8, PyTorch ≥ 1.8). Deps via
[requirements.txt](../../requirements.txt).
